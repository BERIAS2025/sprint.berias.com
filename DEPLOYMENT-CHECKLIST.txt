DEPLOYMENT CHECKLIST
30-Day Clarity Sprint Landing Page
================================================================================

BEFORE UPLOAD:
--------------
□ Unzip the package to your computer
□ Review all files (HTML, CSS, JS, images)
□ Have your cPanel login ready
□ Have tracking codes ready (Google Analytics, Google Ads, Facebook Pixel)
□ Have HubSpot form code ready

UPLOAD PHASE:
-------------
□ Log in to DomainFactory cPanel
□ Navigate to File Manager
□ Find or create /sprint/ directory
□ Upload ALL files from package
□ Verify folder structure is correct:
  □ index.html in root of /sprint/
  □ css/ folder with 2 CSS files
  □ js/ folder with 2 JS files
  □ images/ folder with 21 images
  □ Legal pages (impressum.html, privacy.html, terms.html)
□ Set file permissions (755 for folders, 644 for files)

SSL SETUP:
----------
□ Access SSL/TLS section in cPanel
□ Enable SSL for sprint.berias.com
□ Wait 10-15 minutes for activation
□ Test https://sprint.berias.com
□ Verify padlock icon appears

TRACKING CODES:
---------------
□ Download index.html from cPanel
□ Add Google Analytics code (lines 28-36)
□ Add Google Ads code (lines 42-48)
□ Add Facebook Pixel code (lines 54-68)
□ Save file
□ Re-upload to cPanel (overwrite)
□ Clear browser cache
□ Test tracking (check real-time reports)

HUBSPOT INTEGRATION:
--------------------
□ Log in to HubSpot
□ Create or select contact form
□ Copy embed code
□ Add to index.html (search for "HUBSPOT FORM EMBED CODE")
□ Save and re-upload
□ Test form submission
□ Verify contact appears in HubSpot

FINAL TESTING:
--------------
□ Visit https://sprint.berias.com
□ Test on desktop browser
□ Test on mobile phone
□ Test on tablet
□ Check all images load correctly
□ Test mobile menu (hamburger icon)
□ Click all navigation links
□ Test FAQ accordion (click each question)
□ Verify Calendly widget loads
□ Test Trustindex reviews display
□ Submit test form
□ Check all external links work
□ Verify legal pages accessible
□ Test "Back to Top" functionality
□ Check page load speed (should be under 3 seconds)

BROWSER TESTING:
----------------
□ Google Chrome
□ Mozilla Firefox
□ Safari (Mac/iPhone)
□ Microsoft Edge
□ Mobile browsers (iOS Safari, Chrome)

CONTENT VERIFICATION:
---------------------

□ Calendly link works

□ HubSpot form submissions
